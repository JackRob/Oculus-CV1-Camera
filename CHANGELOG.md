# Changelog

## 0.1.0 — prepared, unreleased

- Experimental Windows x64 installer for one recognized CV1 firmware revision.
- Native MJPEG/UVC profile with automatic USB 2 startup, corrected four-mode negotiation timing and tested exposure values.
- Per-sensor double backup, byte/layout preconditions, constrained writes and physical readback.
- Explicit stock restoration and bounded application recovery from an already-present USB fallback loader.
- Prominent bricking disclaimer, compatibility limits, recovery and privacy guides.
- Synthetic offline tests, hash-pinned setup dependencies and source-only release packaging.

The profile was physically validated on one sensor during development. The combined packaged installer is not broadly hardware-qualified. No firmware dumps, calibration, serials or private capture evidence are included.
